 💬 ChatNest – JavaScript Chat Application

ChatNest is a simple and interactive chat application developed using **HTML, CSS, and JavaScript**. It provides a user-friendly interface for sending messages, viewing conversations, and interacting with a chat-style platform.

 📌 Project Overview

ChatNest is a front-end web project designed to demonstrate how JavaScript can be used to create an interactive chat application. Users can type messages, send them, and view the conversation dynamically without reloading the page.

This project is suitable for beginners who want to learn **DOM manipulation, event handling, arrays, objects, and dynamic content rendering** in JavaScript.

 ✨ Features

* 🏠 Simple and attractive chat interface
* 💬 Send and display messages dynamically
* 👤 User-friendly conversation layout
* 🔄 Real-time UI updates using JavaScript
* 📱 Responsive design for different screen sizes
* 🎨 Clean and modern styling
* ⚡ Fast and lightweight front-end application
* 🧩 Easy-to-understand project structure

 📦 Main Modules

 1. User Interface Module

Provides the layout of the application, including the navigation bar, chat area, input field, and buttons.

 2. Message Module

Allows users to enter and send messages. JavaScript dynamically displays the messages in the conversation area.

 3. Event Handling Module

Handles user actions such as clicking the send button, pressing Enter, and interacting with chat elements.

4. Dynamic Rendering Module

Updates the chat interface dynamically using JavaScript DOM manipulation.

5. Responsive Design Module

Ensures that the application works across desktops, tablets, and mobile devices.
